# Understanding Large Language Models(LLMs)

1. LLM is an AI system trained to understand and generate human language.
It uses ML, particularly deep learning with neural networks, to process and generate text in a way that mimics human-like understanding and conversation.
2. Big tech giant companies, scrape the data, get the data, prepare training data set and train the LLMs.

# Fundamentals of tokenization in NLP

1. Tokenization is a process of converting the user input into set of numbers understandable by the LLMs.
2. The user input is first converted into tokens(into numbers), sent to LLM(transformer) where it predicts the next token repeatedly and then de-tokenize it to human understandable language
